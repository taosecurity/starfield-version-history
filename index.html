Starfield Version History

This page lists every Starfield version from the 2023 review build to today. For each one it shows when it came out, what kind of update it was, and its highlights and links to the patch notes on SteamDB and Bethesda.net.

By Richard Bejtlich, Richard Presents Starfield Essentials on YouTube

    Kinds of version

    Launch

    The launch version is the one the game came out with on 2023-09-06.

    Major update

    A major update is a large update that adds features or content, or comes with an expansion.

    Patch

    A patch is a regular update, made mostly of bug fixes and small improvements.

    Hotfix

    A hotfix is a small, quick fix released soon after another update.

    Beta

    A beta is an update offered first as an opt-in test on Steam before everyone gets it.

    Creation Kit only

    In a Creation Kit only update, the Creation Kit (the modding tool) changed but the game did not.

    Pre-release

    Pre-release builds came before launch: the review copy and early access.

    The same version number can appear twice: once as a Steam beta and again when everyone gets it, or as the early access build and then the launch build.

    Adding a version

    The list lives in one plain file, versions.csv, in the page's GitHub repository. The page reads it every time it opens. To add a version, the repository owner opens versions.csv in GitHub's editor, copies the last line, changes it and commits. The page shows the change a minute or two later. Richard may also ask Claude to update the page with new release data.

    2026-06-11,1.16.244,Patch,Bug updates,https://steamdb.info/patchnotes/23518663/,https://bethesda.net/...,
    • The seven fields are Date, Version, Kind, Highlights, SteamDB link, Bethesda (or other) link and one extra link. Leave a field empty but keep its comma.
    • Dates are written year-month-day, like 2026-06-11. The order of lines doesn't matter; the page sorts them.
    • Kind is one of: Launch, Major update, Patch, Hotfix, Beta, Creation Kit only, Pre-release.
    • Put text that contains a comma in double quotes: "Major update with maps, gameplay".
    • If a line has a mistake, the page still shows all the other lines and names the bad one in a red box at the top.

    Anyone else who spots a wrong date or a missing version can open an issue.

    • This is an unofficial list, not made or endorsed by Bethesda. Starfield is a trademark of ZeniMax Media.
    • Dates are when each version reached Steam (betas: when the opt-in beta opened). Xbox and Game Pass sometimes got an update on a different day.
    • SteamDB keeps the full list of Steam builds, including ones Bethesda didn't announce: steamdb.info/app/1716740/patchnotes.
    • Some updates share one Bethesda article, for example a beta and its full release, so two rows can link the same notes.
