# AGENTS.md: Starfield Version History

Instructions for AI assistants working with this repository.

1. **What it is:** a static web page (`index.html`, published with GitHub Pages at https://taosecurity.github.io/starfield-version-history/) and its data file, `versions.csv`.
   - It lists every Starfield version since the 2023 review build, with its date, kind, highlights and links to the patch notes.
   - Use it to answer questions such as "When did version 1.14.70 come out?" or "Which updates were hotfixes?".
   - It is kept by hand. A version appears only after someone adds its line.
2. **Prerequisites:** to view it, any current web browser. For the check below, Python 3.9 or later (standard library only). To view the page from a local copy, serve the folder (step 4), because browsers block a page opened as a file from reading `versions.csv`.
3. **Install:** none. Get a copy with `git clone https://github.com/taosecurity/starfield-version-history.git`.
4. **Prove it works:** from the repo folder, run the check below. It prints the number of rows, the newest version and any bad rows, for example `36 rows; newest 1.16.244 ; bad: none`.
   ```
   python -c "import csv,datetime as d;K={'Launch','Major update','Patch','Hotfix','Beta','Creation Kit only','Pre-release'};r=list(csv.DictReader(open('versions.csv',encoding='utf-8')));[d.date.fromisoformat(x['Date']) for x in r];bad=[x['Version'] for x in r if x['Kind'] not in K or len(x)!=7 or None in x.values()];print(len(r),'rows; newest',max(r,key=lambda x:x['Date'])['Version'],'; bad:',bad or 'none')"
   ```
   To see the page locally, run `python -m http.server 8000` in the folder and open http://localhost:8000/.
5. **Data:** `versions.csv` has a header line and one line per version, with seven fields:
   - `Date`: the day the version reached Steam (for a beta, the day the opt-in beta opened), as YYYY-MM-DD.
   - `Version`: the version number, such as `1.16.244`. The same number can appear twice, once as a Beta and once when everyone got it.
   - `Kind`: one of Launch, Major update, Patch, Hotfix, Beta, Creation Kit only, Pre-release.
   - `Highlights`: a short description. Quote it with double quotes if it contains a comma.
   - `SteamDB`, `Bethesda`, `Also`: links starting with `https://`, or empty. `Bethesda` may hold another article when Bethesda posted none.
6. **Common tasks:**
   - Add a version: append one line with all seven fields (keep the commas of empty fields), then run the check in step 4. The page sorts lines by date itself.
   - Fix a version: edit its line in place and run the check.
   - Read the list in code: `csv.DictReader(open('versions.csv', encoding='utf-8'))`.
7. **Outputs and exit codes:** the page writes nothing. The check only prints. It exits with code 0, or 1 with a traceback naming the bad date when a `Date` isn't YYYY-MM-DD. There are no logs. The page itself shows any line it can't read in a red box at the top, and shows all the other lines.
8. **Limits:**
   - The page fetches only `versions.csv` from its own site and uploads nothing.
   - Don't edit `index.html` to add data. It holds only the page code and is regenerated by the maintainer.
   - Don't add builds that never reached players (internal or test branches), and don't guess dates: leave a version out until a source confirms it.
9. **Corrections:** open an issue at https://github.com/taosecurity/starfield-version-history/issues, or edit `versions.csv` in a pull request.
